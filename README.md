# Tailvani social autopost

Not part of the Shopify theme. This branch holds the generator used by the
"Tailvani Social Autopost" scheduled task. Shopify only syncs the theme branch,
so nothing here reaches the storefront.

- `tvsocial.py` – renders ad-style posts: 1080x1350 JPEG (templates cover, split,
  thisorthat, edit) or a 1080x1920 9-second MP4 with original generated music.
- `upload.py` – pushes a file to a Shopify staged-upload target.
- `fonts/` – Bodoni Moda, Archivo, Caveat (SIL Open Font License, Google Fonts).
- `mark.png` – Tailvani logo mark.
